# The Funniest AI Excuse

Entry for the make.fun bounty [The Funniest AI Excuse](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0).

`main.py` (Python 3, standard library only) writes one line — at most 200
characters — to `/output/entry.txt`: the funniest excuse an AI agent could
offer after it fails a task.

Run it with:

```sh
python3 -P -s main.py
```
